# Disease Propagation on Networks

This project studies infectious disease spread using network-based models.
We simulate diffusion processes on weighted graphs and analyze the effect
of targeted immunization using spectral graph methods.

## Structure
- `src/` – core simulation and graph code
- `data/` – datasets (not tracked if large)
- `notebooks/` – experiments and visualization
- `results/` – figures and outputs
